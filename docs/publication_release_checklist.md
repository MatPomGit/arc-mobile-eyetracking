# Publication release checklist

- [ ] Every central measurement claim maps to `research/claim_ledger.yaml`.
- [ ] Every reportable result maps to registered evidence with app/estimator/calibration/protocol provenance.
- [ ] Calibration and held-out evaluation targets are demonstrably separate.
- [ ] Invalid/tracking-loss observations are included in failure/missingness reporting.
- [ ] Device and context scope of claims matches the tested envelope.
- [ ] Internal screen-target validation is not described as laboratory-eye-tracker equivalence.
- [ ] External-reference claims, if any, have independent reference evidence and synchronization provenance.
- [ ] Raw face/room imagery and direct device identifiers are absent from the release unless separately justified and governed.
- [ ] Protocol deviations are recorded.
- [ ] Null/negative/device-failure findings relevant to the scope are not selectively omitted.
- [ ] Tables/figures/numerical values are generated from versioned analysis artifacts.
- [ ] Citations support the claims they accompany.
- [ ] Exact release commit/tag is recorded.

# P01: Mobile gaze measurement validation

Working scope: validation of on-device Android gaze estimation as a research measurement instrument.

The first manuscript should focus on calibration repeatability, held-out screen-space accuracy/precision, failure rate, robustness to prespecified context changes and device heterogeneity. External laboratory eye-tracker agreement is a separate evidence tier and may be added only when a proper reference protocol exists.

Do not write Results before registered evidence exists. Planned claims and their evidence IDs should be tracked in `research/claim_ledger.yaml`. Use `docs/publication_release_checklist.md` before submission.
